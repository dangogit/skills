# הסקילים שלי ל-Claude Code

אלה הסקילים שאני עובד איתם בפרויקטים של לקוחות. כל סקיל הוא תיקייה עם קובץ `SKILL.md`, ו-Claude Code טוען אותו לבד כשמגיעה משימה שמתאימה לו. אני מוסיף לכאן סקיל כשהוא עובד גם מחוץ למחשב שלי, אז שווה לעדכן מדי פעם.

## התקנה

בתוך Claude Code (לא בטרמינל):

```
/plugin marketplace add dangogit/skills
/plugin install daniel@daniel-goldman
```

או מהטרמינל, לסקיל אחד:

```bash
npx skills add dangogit/skills --skill client-project-proposal
```

הריפו פרטי בינתיים. אם קיבלת הזמנה ל-GitHub, תאשר אותה קודם, אחרת ההתקנה לא תמצא אותו.

## מה יש כאן

| סקיל | מה הוא עושה |
|---|---|
| `client-project-proposal` | לוקח פגישה, הודעות ואפיון של לקוח, מעריך כמה ימי עבודה זה, ומוציא הצעת מחיר PDF ממותגת בעברית. |

## הצעת מחיר ללקוח

זה הסקיל שאיתו אני מוציא הצעות מחיר. אתה נותן לו את החומרים של הלקוח, והוא:

1. קורא את התמלול, ההודעות והאפיון, ושואל רק את השאלות שמשנות את המחיר.
2. מפרק את העבודה לשלבים ומעריך כל שלב בימי עבודה. הימים והמחיר ליום נשארים אצלך.
3. בונה הצעה ללקוח: מה כואב לו היום, מה המערכת עושה, שלבים עם תאריכים, לוח זמנים, מחיר כולל אחד, תנאי תשלום, מה כלול ומה לא.
4. מרנדר PDF בעברית מימין לשמאל עם הלוגו והצבע שלך, ובודק כל עמוד לפני שהוא מחזיר לך אותו.

הוא לא שולח כלום ללקוח ולא מתחיל עבודה. את ההצעה אתה קורא, מאשר ושולח.

### לפני הפעם הראשונה

פתח את `references/defaults.md` בתוך הסקיל ומלא את מה שבסוגריים מרובעים: השם שלך, פרטי העסק, המחיר שלך ליום עבודה, הלוגו, צבע המותג ואיפה לשמור הצעות. אם לא תמלא, Claude ישאל אותך בפעם הראשונה וימלא בעצמו.

באותו קובץ יש ברירות מחדל שאני עובד איתן, ואפשר לשנות כל אחת:

- הלקוח רואה מחיר אחד לכל המערכת, בלי מחיר לכל שלב ובלי ימי עבודה. ככה אי אפשר לחשב ממנו את המחיר שלך ליום.
- 50% לפני שמתחילים, 50% במסירה.
- 30 ימי הרצה אחרי המסירה כלולים במחיר, לתיקוני באגים והתאמות קטנות.
- לכל שלב יש תאריכים, מתאריך התחלה שכתוב בהצעה.
- ההצעה לא מזכירה באילו כלים אתה בונה.

### איך משתמשים

תכתוב ל-Claude משהו כמו:

```
תכין הצעת מחיר ללקוח לפי התמלול ב-meeting.md והאפיון ב-docs/spec.md
```

או תפעיל ישירות עם `/daniel:client-project-proposal`.

### מה צריך במחשב

- Google Chrome, בשביל לרנדר את ה-PDF. בלינוקס או בנתיב אחר מעבירים `--chrome`.
- poppler, בשביל לבדוק את העמודים: `brew install poppler` במק.
- Python 3.
- רק אם רוצים קובץ Word במקום PDF: `python3 -m pip install python-docx`.
