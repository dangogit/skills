# Discovery and high impact questions

Bound searches to the resolved client and project. Read the call's relevant discussion, current messages and supplied artifacts. Do not ask for material already available.

## Sources

- Meeting: use an owned transcript or meeting-note page. Distinguish source transcript from summary; exhaust continuation before claiming something was not discussed.
- Messages: use a supported read-only connector or an export the user provides. Scope reads to the client's conversation and relevant forwarding context. Reading is not sending authority.
- Answers: read the current document through access checks without changing it. A direct answer may narrow or supersede the first specification.
- Attachments: inspect actual type. A `.doc` can be an Outlook message, and a portal-link email is not the brief. Inspect its body and attachment inventory.
- Workbooks: inspect input/formula ranges, locks, hidden content and variants. A filled example is not necessarily submitted. Saved formulas are not recalculation or portal acceptance proof.

Keep originals intact and case evidence within the case workspace. Never retain secrets, authenticated browser state or full unrelated inbox exports. Do not upload client material to research services.

## Scope differences

Record consequential conflicting source locations, the latest answer and the estimate implication. Test distinctions when applicable: recording outcomes versus managing delivery; storing suppliers versus recommendations; one inbox versus portal integrations; manual input versus reply extraction; new records versus migration; one template family versus arbitrary workbooks; ordinary hosting versus a mandatory processing location.

These examples are not a universal questionnaire. Ask only what changes the quote. A bounded assumption can settle a configurable detail; a real security restriction or product fork cannot be silently removed.

## Short clarification draft

Use numbered, plain-language decisions. Count actual questions, not headings: ten decisions should not be disguised as four sections. Explain a source conflict respectfully, such as a feature deferred in scope but included in the workflow.

Request representative materials concretely: original input, completed output and another format only if used. Request material the client may share. Do not require every sample before giving an honestly bounded preliminary estimate.

After answers arrive, update the scope and continue toward the proposal. Do not repeat settled questions or turn optional work into confirmed scope.
